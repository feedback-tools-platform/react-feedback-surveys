## Quick Start

Install the package:

```bash
npm i react-feedback-surveys
# or
yarn add react-feedback-surveys
```

Import styles and render a survey:

```tsx
import { Surface, Survey } from 'react-feedback-surveys';
import 'react-feedback-surveys/index.css';

function App() {
  return (
    <Surface theme="auto">
      <Survey
        type="csat"
        points={5}
        scaleStyle="emoji"
        question="How satisfied are you with our product?"
        minLabel="Very unsatisfied"
        maxLabel="Very satisfied"
        thankYouMessage="Thanks for your feedback!"
        onScoreSubmit={({ value }) => console.log('Score:', value)}
      />
    </Surface>
  );
}
```

## Survey Formats

One `Survey` component covers every format, picked with the `type` prop:

- **`type="csat"`** - Customer Satisfaction Score, 2 or 5 points (`points={2}` or `points={5}`)
- **`type="nps"`** - Net Promoter Score, 0–10 scale
- **`type="ces"`** - Customer Effort Score, 7-point scale
- **`type="general"`** - text feedback only, no rating scale

## Layout Components

- **Popup** - Fixed overlay wrapper with positioning and animations
- **Surface** - Inline container for embedding a survey in the page

Both take a `theme` prop: `light` (default), `dark`, or `auto`.
